# Presentations

Version-controlled sources for project presentations. Each deck has its own
build instructions and dependencies. Generated slide files, PDF exports, and
installed dependencies are not tracked.

- [Infer-stack technical overview](infer-stack/README.md) — 18-slide introduction,
  architecture walkthrough, quickstart, and November 2026 benchmark case study.

To add a deck, put its source and build instructions in a separate subdirectory.
Keep editable source and non-sensitive data here; write generated artifacts to
that deck's `build/` directory.
