# Code audit — 2026-07-02

Branch: `infer-stack-cli-api-migration` (HEAD `caa6750`). Test suite: 247 passed, 1 skipped.
Six parallel subsystem audits (leasing core, compose/placement/catalog, CLI, TUI, core utils,
experimental) plus manual verification of the highest-impact claims. Items marked **[verified]**
were re-checked line-by-line in the source by the coordinating reviewer.

Security calibration (per Jon): infer-stack runs on trusted multi-user hosts — access to the
system implies access to the environment, so local-user-readable files are *not* critical;
group-level scoping is the target. What *does* matter is keeping plaintext keys out of logs,
tracebacks, process argv, and generated/copied commands — prefer env-var indirection such as
`$(infer-stack env LITELLM_MASTER_KEY)`.

## P0 — leasing correctness (lease/GPU safety)

1. **`Ledger.renew` resurrects RELEASED/EXPIRED leases** [verified] — `leasing/ledger.py:175-188`.
   The only guard is "lease row exists"; `renew_lease` unconditionally sets `state=ACTIVE`.
   A late heartbeat after expiry+sweep re-activates a lease whose deployment is already
   idled/stopped/pruned — no `bump_desired_generation`, no re-LIVE. The CLI then prints
   `renewed <id>` as if the endpoint still runs. Guard on state (only ACTIVE renews; return
   None or a distinct "lapsed" result otherwise).

2. **`release <id>` reports success and exits 0 for a nonexistent/already-released lease**
   [verified] — `cli/commands_leasing.py:869-871`. `Ledger.release()` returns an empty
   `ReleaseResult` instead of raising, and `ReleaseCLI` unconditionally sets `released = [sid]`.
   A typo'd lease id in a pipeline "succeeds" while the real lease keeps pinning a GPU.
   (`RenewCLI` at :1168 checks for None — mirror that.)

3. **`apply_now` publishes a post-apply generation** [verified] — `leasing/controller.py:514-528`.
   It calls `set_applied_generation(self.ledger.desired_generation())` *after* `apply_fn()`
   finishes. If another process renders gen N+1 while the apply runs, applied_gen is bumped to
   N+1 without those files having been up'd — the waiter sees `applied >= target` and returns,
   and its deployment never comes up (and no future coalesced apply fixes it, since
   applied ≥ desired). Snapshot `desired_generation()` *before* `apply_fn()` (as
   `_ensure_applied` already does at :480).

4. **Rollback paths skip re-render, leaving phantom deployments** — `leasing/controller.py:627-631,
   653-655`. On `ConvergeAborted` and `PlacementError` during acquire, the controller calls
   `ledger.release(...)` (bumps desired gen) but never re-renders; the on-disk compose project
   still contains the rolled-back deployment. A concurrent `_ensure_applied` waiter then applies
   the stale render and publishes applied_gen covering the release — the phantom container comes
   up and stays up. The wait-timeout path correctly uses `self.release()`; these two should too.

5. **TTL expiry during the placement queue returns "success" with a dead lease** —
   `leasing/controller.py:639-652`. Each retry's `_render()` sweeps; if `ttl_seconds` is shorter
   than the queue wait, the caller's own lease expires, its deployment leaves the desired set,
   `unplaced` empties, and the loop exits into the success path — env-file handed out for a
   deployment being torn down. Recheck `result.lease.is_protecting` (or exempt the caller's
   lease from sweep while queued).

6. **`except TypeError` converge-signature probe swallows real TypeErrors** —
   `leasing/controller.py:421-426`. A TypeError raised *inside* a modern backend's
   `converge(desired, apply=False)` is misread as "legacy signature" and the call is retried
   as `converge(desired)` — i.e. a full render+apply inside the render-only critical section,
   masking the original traceback. Probe with `inspect.signature` instead.

7. **Pruned deployments leak backend containers on the realize/teardown path** —
   `leasing/controller.py:449-456`. `stale = actual - desired_ids`, then `by_id.get(gid)`
   returns None for a pruned ledger row and the container is silently skipped forever.
   At minimum warn; better, let backends tear down by id.

8. **`evict_idle` never rechecks demand** — `leasing/ledger.py:220-241`. It stops anything
   `state == IDLE` even if demand > 0 (reachable via finding 1's resurrection, or any future
   path that misses a re-LIVE transition). A demand recheck inside the transaction is cheap
   insurance.

9. **Fresh-DB concurrent open can crash on schema-version insert** — `leasing/store.py:140-149`.
   Two processes both see no `schema_version` row and both INSERT; the loser gets
   `IntegrityError`, which `_retry_locked` re-raises (it only retries "locked"). A batch of
   pipeline jobs against a brand-new ledger can crash one at open. Fix: `INSERT OR IGNORE`.

## P0 — placement / compose rendering

10. **`pipeline_parallel_size` is neither counted nor passed to vLLM** [verified] —
    `leasing/placement.py:72-77` (`required_gpu_count` = tp × dp only) and the render path
    never emits `--pipeline-parallel-size`. A PP=2 endpoint gets 1 GPU and runs unsharded → OOM.
    Related inconsistency: `data_parallel_size` *is* counted but is absent from
    `VLLM_STRUCTURAL_FIELDS`, so endpoints differing only in dp coalesce into one deployment.

11. **Catalog knobs `revision`, `quantization`, `dtype`, `chat_template`, `trust_remote_code`,
    `image` are silently dropped from the rendered vLLM command** — `leasing/compose.py:218-233`
    + `leasing/catalog.py:380-386`. They flow into the compat key (so they *distinguish*
    deployments) but never reach the container. `quantization: awq` serves the full-precision
    `main` revision with no warning.

12. **Compose service-name collisions silently drop a live deployment** [verified] —
    `leasing/compose.py:810-827`. `services[name] = ...` overwrites on key collision (served
    names collapsing under `_dns_slug`, two Ollama deployments sharing a host with different
    structural settings). The earlier deployment's container never exists; probes report
    "container not running" until lease timeout with no error anywhere. Add a collision check
    that surfaces as a render error.

## P1 — data-loss / hang risks in utilities

13. **`docker_rm_dirs` interpolates unquoted names into `sh -c 'rm -rf …'`** [verified] —
    `docker_utils.py:255-272`. A state path whose last component contains a space or glob
    deletes *sibling* directories inside the bind-mounted parent. Pass argv
    (`['rm','-rf',*paths]`) or `shlex.quote` each name.

14. **`nvidia-smi` subprocess has no timeout** — `hardware.py:11`. A wedged driver (common
    failure mode) hangs every CLI invocation forever. Also `hardware.py:62-63`:
    `int(float('[N/A]'))` on MIG/fallen-off-the-bus GPUs crashes `detect_inventory()` instead
    of skipping the GPU.

15. **`our_published_ports` crashes on empty `docker compose ps --format json` output** —
    `docker_utils.py:139-162`. `[]` falls through to line-parsing and `.get` is called on a
    list → `AttributeError` aborts pre-flight on a zero-container project.

16. **`_reconcile_routes` blocks apply for up to ~3 min when the gateway is down** —
    `leasing/compose.py:1377,1442-1461` (90 × 2 s). A crash-looping litellm container makes
    every acquire/release/gc hang before the "leaving it for next converge" warning.

## P1 — secrets in logs/argv/commands (per the agreed posture)

17. **HF token on helm argv and embedded in `CommandError` text** — `kubeai_ops.py:14-19,62-65`.
    `--set secrets.huggingface.token=<token>` is visible in `ps`, and on failure the raised
    error message (→ tracebacks, CI logs) contains the raw token. Use `--set-file`/stdin values
    and redact argv in the error.

18. **TUI "Copy curl" bakes the literal master key into the command** [verified] —
    `tui.py:2151-2165`. Emit `Authorization: Bearer $LITELLM_MASTER_KEY` (or
    `$(infer-stack env LITELLM_MASTER_KEY)`) instead, so pasted/logged commands don't carry
    the plaintext key.

19. **Catalog-controlled strings are subject to docker-compose `${...}` interpolation** —
    `leasing/compose.py` rendered args/env. `yaml.safe_dump` doesn't escape `$` as `$$`, and
    the project is composed with `--env-file` pointing at the secrets env. An `extra_args`
    entry containing `${LITELLM_MASTER_KEY}` would substitute the key onto a container command
    line (visible in `docker ps`/logs). Escape `$` → `$$` when rendering.

20. **`.env` written with default umask (0644) and a stray `print` to stdout** —
    `env_utils.py:96-97`. Per posture: group-scope it (0640/0660 + group ownership) rather
    than 0600; move the "Write .env to …" line to stderr (it pollutes machine-read stdout,
    contradicting `_log.py`'s own rule).

21. **`/tmp` fallback lock file is predictable and symlink-followable** —
    `leasing/controller.py:197-249`. Lower priority under the trusted-user model, but a
    pre-planted symlink/held flock blocks every mutating verb indefinitely (no lock timeout).
    `os.open(..., O_NOFOLLOW)`, a per-group subdir, and a bounded `LOCK_NB` retry with a
    "who holds it" diagnostic would harden this cheaply.

## P1 — CLI correctness / script-facing contracts

22. **`evict --json` mixes human text into the JSON stream** [verified] —
    `commands_leasing.py:954-955`. `no idle deployment for: …` prints to stdout before the
    JSON document. Move to stderr or into the payload.

23. **Re-running `config init` destroys a dict-valued `reverse_proxy` setting** [verified] —
    `commands_meta.py:445,463-465`. `_as_bool({...})` is always False, so a configured
    `{enabled, port, config_path}` block is rewritten to `reverse_proxy: false` despite the
    "keeps your other settings" promise.

24. **`--ttl 0` silently means infinite** — `commands_leasing.py:74-77`. `'0'` is in the
    none/inf set; a script that computes a TTL rounding to 0 gets a standing infinite lease.
    Undocumented; at minimum document, better make `0` an error.

25. **`INFER_STACK_ALLOWED_GPUS` honored by `catalog suggest` but ignored by
    `acquire`/`release`/`evict`/`gc`** — `commands_leasing.py:94-97,232` vs `cli/context.py:42-93`.
    Duplicated `--allowed-gpus` parsing with divergent behavior (and the local copy tracebacks
    on `--allowed-gpus x,`). Unify on `context.effective_inventory`.

26. **Exit-code and JSON-schema inconsistencies** — `run` exits 1 on readiness timeout where
    `acquire` exits 2 and prints a raw repr (`commands_leasing.py:1227-1231`); `acquire --json`
    encodes `pending` as arrays while `wait --json` uses objects (`:404-411` vs `:1088-1094`);
    `evict <live-name>` exits 0 on no-op (`:956-962`); `catalog suggest` exits 0 when nothing
    fits (`commands_catalog.py:280-287`).

27. **Traceback-instead-of-error paths** — `release/renew --env-file <missing>` →
    `FileNotFoundError` (`envfile.py:128-131`); non-mapping catalog.yaml → `AttributeError`
    (`commands_catalog.py:70-74`); missing `$EDITOR` binary → `FileNotFoundError` and an
    editor path with spaces breaks under `.split()` (`commands_catalog.py:400`,
    `commands_meta.py:563`); `logs --follow` Ctrl-C → `KeyboardInterrupt` traceback
    (`commands_runtime.py:300`); `Confirm.ask` on non-interactive stdin → `EOFError`
    (`diff_prompt.py:118`).

28. **`catalog … --dry-run` lies twice** — `commands_catalog.py:85-96` skips validation, so the
    preview can show a catalog the real write would reject; `:147-149` prints `removed '<name>'`
    on a dry run.

## P1 — TUI

29. **Logs pane never reattaches after the stream dies / compose project appears** —
    `tui.py:1409,1447-1477`. Mount before first acquire leaves a dead `docker compose logs -f`;
    nothing retries on stream end, and the collapse/expand recovery only fires when
    `_log_proc is None`. The pane stays silently dead for the session.

30. **Cursor restored by index, not row id → destructive action on the wrong lease** —
    `tui.py:1189-1195,1284-1289,1530-1532`. A poll rebuild between highlight and the Release
    keypress shifts rows; Release/Evict (no confirmation) then act on whatever lease now sits
    at that index. Restore cursor by matching the previously-cursored id.

31. **Refresh workers are `exclusive=True` but never check cancellation, and the monkeypatched
    `backend.run` has no subprocess timeout** — `tui.py:870-881,1049-1053,1136-1139`. A wedged
    dockerd spawns a new stuck thread every tick until the executor pool is exhausted; a slow
    stale poll can also render pre-mutation state *after* a release ("the lease came back").
    Check `get_current_worker().is_cancelled` before `call_from_thread(self._render, …)` and
    add a timeout to `quiet_run`.

32. **Log-proc switch race + zombie** — `tui.py:111-117,1456-1472`. Rapid service switches can
    orphan a `logs -f` process (terminate runs before `_log_proc` is assigned); `terminate()`
    never `wait()`s after `kill()` and never closes stdout; and it runs on the UI thread with a
    2 s wait.

33. **Smaller TUI items** — double-click gate keys on row index and ignores `event.button`
    (`:1701-1711`); `_fill_catalog` rebuilds without cursor/scroll restore (`:942-964`, sibling
    of the fixed bug); scroll restore lost when two rebuilds land in one frame
    (`:1190-1195,1290-1292`); ctrl/shift-click on blank area toggles the stale cursor row
    (`:1728-1731`); `_lease_sel`/`_dep_sel` mutated from worker threads without marshalling
    (`:2305,2332,2347`); mutations don't invalidate `_observed_at` so "running" columns lag
    (`:2364-2366` — one line: `self._observed_at = None`); `_copy` runs subprocesses on the
    event loop (`:1508-1528`); `_install_quiet_docker`/logger-disable never restored on unmount
    (`:864-883,2402-2407`); `_render` not armored so one transient render exception kills the
    app (`:1137-1139`); endpoint-edit wizard silently drops an explicit
    `enable_prefix_caching: false` (`:279-280,2001-2002`); `_curl_for` also breaks on
    apostrophes in the prompt (`:2158-2164`, fix together with item 18).

## Verified non-issues (checked deliberately, no action needed)

- TTL boundary arithmetic is consistent (`expires_at > now` protecting vs `<= now` due).
- `set_applied_generation` upsert is correctly monotonic.
- `write_env_file` is merge-preserving — no secret clobbering between `master_key()`/`db_password()`.
- PyYAML port-string sexagesimal quoting is not triggerable with these container ports.
- Ollama `CUDA_VISIBLE_DEVICES` vs `device_ids` reservation is correct as commented.
- Positional host-port renumbering with the gateway off is a documented trade-off.
- `probe.py` timeouts/error handling are sound; auth headers never appear in reason strings.
